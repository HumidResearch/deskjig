DeskJig is now built exclusively for Apple Silicon.

## What's changed

- **Apple Silicon only**: DeskJig now requires a Mac with Apple Silicon
  (M1 or later). Releases no longer include an Intel (x86_64) slice —
  if you're on an Intel Mac, v1.1.3 is the last version that runs there.
- CI hardening: the build cache now fails loudly instead of silently
  degrading when the cache backend misbehaves.
