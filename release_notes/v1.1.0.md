Quick Switch grows a tmux control panel, and workspace cleanup finally reaches your terminal sessions.

## What's new

- **tmux settings in Quick Switch** — the Quick Switch pane now has a gear that
  opens a full settings page: socket path, worktree defaults, and your tmux
  install status, reachable from every pane state (including the empty state
  before you add a root folder).
- **Session cleanup on workspace delete** — deleting a workspace now kills the
  tmux sessions it owned, so old `bento_*` sessions no longer pile up on the
  socket.
- **DeskJig-named tmux socket** — managed sessions now live on
  `/tmp/deskjig-tmux-<uid>.sock`, and worktrees default to
  `~/.deskjig/worktrees`. Sessions on the old `bento-tmux` socket are left
  untouched (see `docs/LEGACY_IDENTIFIERS.md`).

## Fixes

- The workspace creator no longer ignores clicks on an app when no zone is
  selected — the app lands in the first zone of the current monitor instead of
  silently doing nothing.
- The Add-apps list no longer shows duplicate entries for the same app, and
  apps installed in `~/Applications` now show up.
- The category filter in the app picker survives typing in the search field.
- Restoring a workspace no longer crashes apps that were cold-launched by the
  restore (notably Apple Notes): window positioning now waits for the app to
  finish launching.
